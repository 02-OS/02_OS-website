An operating system for the agent working in the repo.

02_OS pairs a GNOME desktop with a local repository runtime. The runtime reads the tree, the git history, and the symbols, then hands a coding agent a bounded evidence package. Nothing in that path requires an account or a cloud model.

01 / Shell

Desktop

GNOME 51, Pop Shell tiling, and a dock with the installer, files, Chrome, Brave, and a terminal. The login screen opens with the 02 mark, then the normal sign-in is there.

02 / Intelligence

Runtime

02 and 02-agentd keep a local evidence graph: tree-sitter symbols, git diffs, and SQLite. Agents talk to it over MCP. The model, if you use one, stays outside the OS.

03 / Isolation

Local

No telemetry, no cloud database, and no account. The live image signs in as live / live. The installed system uses the account you create.

Evidence path
worktree + git diff → tree-sitter + SQLite → 02-agentd (MCP) → bounded context

    05 / Schedule

    A daily ISO

    A daily image is one whole .iso you install and use as the machine. The download above is still v2026.10.24, published 24 Oct 2026 as split parts. These dates are targets. A missed gate moves every date after it.

    1. Now

      No daily image

      Host tests of the current source pass. That source has no ISO, and it has not been booted. The file you can download is the October public alpha.

    2. 15 Nov

      Candidate

      One whole ISO and its sha256, built from the current source. The build needs 20 GiB free. This file is for the next two checks, not for daily use.

    3. 22 Nov

      Live boot

      That ISO boots on UEFI: splash, sign-in, desktop, network, files, and a terminal.

    4. 29 Nov

      Install

      A fresh install on a disposable disk, then a reboot into that system. The account is the one created in the installer.

    5. 6 Dec

      Personal daily ISO

      One work day on that install, including suspend and a reboot. Published as a single ISO plus checksum. This is a personal image, not a public production release.

    6. Open

      Public daily release

      No date. It starts only after the personal image has been the machine for a week.
