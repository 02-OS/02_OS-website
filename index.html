02_OS
Desktop Try it Source
Public alpha local-first · Git-aware · agent-native

An operating system for the agent working in the repo.

02_OS pairs a GNOME desktop with a local repository runtime. The runtime reads the tree, the git history, and the symbols, then hands a coding agent a bounded evidence package. Nothing in that path requires an account or a cloud model.

Download the latest release GitHub

The button follows the newest GitHub release. Clicking it starts the download. Opening this page does not.

01 / Shell

Desktop

GNOME 51, Pop Shell tiling, and a dock with the installer, files, Chrome, Brave, and a terminal. The login screen opens with the 02 mark, then the normal sign-in is there.

02 / Intelligence

Runtime

02 and 02-agentd keep a local evidence graph: tree-sitter symbols, git diffs, and SQLite. Agents talk to it over MCP. The model, if you use one, stays outside the OS.

03 / Isolation

Local

No telemetry, no cloud database, and no account. The live image signs in as live / live. The installed system uses the account you create.

Evidence path
worktree + git diff → tree-sitter + SQLite → 02-agentd (MCP) → bounded context
